物理基礎 —— 聲音的「時間差」

TDOA — Time Difference of Arrival

人類之所以能分辨聲音從哪裡來，是因為我們有兩隻耳朵。聲音從左邊傳來，會先到達左耳，再到達右耳。大腦透過這個「微小的時間差」，就能推算出角度。麥克風陣列也是一模一樣的原理。

核心公式
ΔL = d · sin(θ)
τ = d · sin(θ) / c
θ = arcsin(τ · c / d) ← 反推角度！
💡 新手提示： 如果你知道麥克風距離 d、音速 c，且能算出時間差 τ，就能反推聲源角度 θ。這是所有 DOA 演算法的最底層邏輯。

訊號處理 —— 精準算出時間差

GCC-PHAT — Generalized Cross-Correlation

在真實世界中有冷氣聲、牆壁回音，兩條聲波混在一起，要怎麼找出那個 τ？這時需要 GCC-PHAT。

乾淨環境下，互相關函數有一個明確的尖峰，容易判斷時間差 τ。

GCC-PHAT 公式
R(τ) = ∫ [X₁(f) · X₂*(f) / |X₁(f) · X₂*(f)|] · e^(j2πfτ) df
→ FFT → 互功率頻譜 → 除以絕對值(PHAT) → IFFT → 找峰值
